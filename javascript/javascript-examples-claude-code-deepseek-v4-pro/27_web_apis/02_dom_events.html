DOM 事件：捕获、冒泡、委托

右侧的日志按"事件真实发生的顺序"记录。先点几下左侧的按钮，再回头看日志， 就能直观地看到事件的传播过程。

1. 事件传播：捕获 → 目标 → 冒泡

三个嵌套盒子，每个盒子都注册了"捕获"和"冒泡"两个监听器。 点击最里面的按钮，观察日志顺序。

div#box-outer（最外层）
div#box-middle（中间层）
div#box-inner（最内层 = 事件目标所在）

2. stopPropagation：把事件截在半路

勾选后，中间层的监听器会调用 stopPropagation()， 最外层的冒泡监听器就收不到事件了。

（这两个开关只影响面板 1 里的三个盒子）

3. 事件委托：1 个监听器管所有条目

只在 ul 上注册了 1 个 click 监听器，点击任意 li 都能被它捕获。点「动态新增」加一个条目试试——新条目无需重新绑定事件。

  • 条目 1：买牛奶
  • 条目 2：写代码
  • 条目 3：遛狗

a) 点击下面的锚点链接，默认行为是跳到页面底部的 #bottom 位置。 勾选后默认行为被阻止，页面不会跳。

→ 点我跳到页面底部（href="#bottom"）
