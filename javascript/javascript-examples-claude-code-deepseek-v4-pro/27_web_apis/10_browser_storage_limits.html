浏览器存储的容量限制

本页会真的往 localStorage 里写数据来做容量探测 —— 探测结束后会把测试数据 全部清理干净，不会影响你自己的网站数据（本页是 file:// 或独立域名）。

1. 体积换算：一段文字到底占多少字节

2. 真实配额探测：把 localStorage 写满为止

不断写入 1MB 的数据块，直到浏览器抛 QuotaExceededError，从而测出真实的配额。 不同浏览器、不同模式（普通/无痕）结果差别很大。

3. navigator.storage.estimate()

浏览器官方提供的容量查询接口，统计的是整个源。

4. 压缩对比：同样 5MB 能多存多少

用 200 条模拟记录对比三种存法：原样 JSON、去掉重复键名、LZ78 压缩。 压缩这里用自己实现的极简 LZ78（真实项目里请用 gzip / pako）。

5. LRU 淘汰模拟

一个容量只有 300 字节的模拟存储：写满之后，最久没被"读取"的键会被淘汰。 输入键和值，点写入；点读取会把该键标记为最近使用。
