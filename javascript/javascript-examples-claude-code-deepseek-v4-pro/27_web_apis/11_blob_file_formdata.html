Blob / File / FileReader / FormData

二进制数据在浏览器里怎么表示、怎么读、怎么传？本页用真实 API 一步一步演示。 所有演示都能离线运行；点「选择文件」时浏览器只会读取你选中的那个文件，不会上传到任何地方。

1. Blob：创建与读取

Blob = 一段不可变的字节 + 一个 MIME 类型。size 数的是字节， 不是字符——中文在 UTF-8 下占 3 字节。

2. File：文件对象与 FileReader

可以点按钮挑一个你自己的文件；也可以点「用内置假文件」在没有任何文件的情况下看效果。

3. 大文件切片（分片上传思路）

blob.slice(start, end) 是分片上传的基础： 每片单独发一个请求，失败只重传那一片。

4. FormData：文本 + 文件一起提交

FormData 被 fetch 发送时会自动编码成 multipart/form-data。 下面按钮会手写这段编码，把"上传到底发了什么字节"摊开给你看。

5. file:// 协议下的限制演示

本页是双击打开的，地址栏是 file://。Blob 家族全部可用， 但"用代码去读本地文件"会被同源策略拦住。点下面按钮看看会发生什么。
