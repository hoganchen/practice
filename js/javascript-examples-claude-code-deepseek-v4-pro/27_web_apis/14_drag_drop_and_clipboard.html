4. 拖放的事件顺序

dragstart 源元素，只触发一次，唯一能 setData 的时机 ↓ drag 源元素，持续触发（约每 350ms 一次） ↓ dragenter 进入目标（会因划过子元素而反复触发） ↓ dragover 在目标上持续触发 ← 必须 preventDefault()，否则 drop 不触发 ↓ dragleave 离开目标（同样会因划过子元素而反复触发） ↓ drop 松手时在目标上触发 ← 在这里读 dataTransfer 的数据 ↓ dragend 源元素，无论成功失败都触发，适合做收尾清理

记忆口诀：想接收拖放，dragover 和 drop 两个都写 preventDefault()。
