知识点速查

validity.valueMissing 必填为空 · validity.patternMismatch 正则不匹配 · validity.tooShort 太短 · validity.typeMismatch 类型不符（如 email） · validity.rangeUnderflow 小于 min · validity.customError 自定义错误

方法：checkValidity() 只判断 · reportValidity() 判断并弹提示 · setCustomValidity(msg) 写入自定义错误（传空串清除）
