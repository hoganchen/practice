三大观察者：IntersectionObserver / MutationObserver / ResizeObserver

页面左侧是三个可以真实交互的演示，右侧日志区实时打印每个观察者回调收到的内容。 请一边操作一边看日志，特别留意「回调是在什么时候被触发的」。

1. IntersectionObserver —— 可见性监测

下面是个可滚动容器（高 240px）。每个条目被观察：一旦有 30% 进入容器可视区， 就会被标绿并打印相交比例。滚到底部的橙色哨兵会触发"加载下一页"。

↓ 哨兵：我进入可视区就加载下一页

2. MutationObserver —— DOM 变化监测

下面的虚线框被观察，开关全开（childList / attributes / characterData / subtree / 记旧值）。用按钮改它，日志里会看到**一次性批量**投递的记录。

  • 条目 B

3. ResizeObserver —— 尺寸变化监测

下面这个蓝色盒子可以拖动右下角改变大小（CSS resize: both）， 也可以用滑块改宽度。每一次尺寸变化都会触发回调。
