1. 模块作用域 vs 普通脚本作用域

普通 <script> 里的顶层变量会挂到 window 上； <script type="module"> 里则不会 —— 它有独立作用域。

2. 动态 import()：真正跑一遍导入导出

静态 import 需要外部 .js 文件（file:// 下会被 CORS 拦截）， 而动态 import() 可以加载 Blob URL， 于是我们能在页面里现场"造一个模块"再导入它。

3. 静态 import 该怎么写（代码对照）

下面这些写法需要真实的外部模块文件。把它们放到用 HTTP 服务器打开的页面里 就能工作；用 file:// 双击打开时，浏览器会以 CORS 为由拒绝加载外部模块。 

// ---- 被导入的模块 utils.js ----
export const VERSION = '1.0.0';        // 具名导出
export function greet(name) {
  return `你好，${name}!`;
}
export class Counter { /* ... */ }
export default function createApp() {} // 默认导出

// ---- 导入方 main.js ----
import createApp, { VERSION, greet } from './utils.js';
import { greet as hi } from './utils.js';   // 重命名
import * as utils from './utils.js';        // 命名空间
import './side-effect.js';                  // 只为副作用
const mod = await import('./lazy.js');      // 动态导入

// ---- HTML ----
// <script type="module" src="./main.js"></script>

要点：路径必须写全 .js 扩展名并带 ./， 且是"相对于当前模块文件"，不是相对于 HTML 页面。

4. 模块的六条硬规矩

1. 顶层自动是严格模式，不用写 'use strict'。
2. 顶层 this 是 undefined，不是 window。
3. 模块只被求值一次，无论被 import 多少次（单例）。
4. 导出的是"实时活绑定"，模块内部改变量，导入方看到新值。
5. 导入的绑定是只读的，导入方不能赋值。
6. import/export 只能写在顶层，不能塞进 if 或函数里。
